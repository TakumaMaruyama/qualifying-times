`data/standards/regional-current.json` の `time` は取り込み形式に合わせた文字列（例 `29.80`、`1:02.34`）で、整数ミリ秒への変換はしていない。`course` は既存の同一大会キーに合わせ `ANY` とした。鹿児島県選手権の別表2と短水路記録会の標準表には「短水路・長水路問わず上記の記録を突破」と明記され、桜島カップ要項の参加資格(3)にも「長水路・短水路を問わない」とある。西日本年齢別・九州カップの各標準表はコース別欄のない日水連資格級の単一表だが、標準表ページに同じ文言は確認できないため、`ANY` を両コースの記録で参加可能という追加の断定には使わない。

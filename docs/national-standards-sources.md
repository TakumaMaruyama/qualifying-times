# 全国大会標準記録の確認記録

確認日: 2026-09-09（Asia/Tokyo）

`data/standards/national-current.json` は、連盟の公式一次資料に掲載された個人・リレーの標準記録を取込用の `SS.ss` / `M:SS.ss` 文字列へ整形したデータである。大会日・会場などの表示用情報は含めない。既存の2025年度 `meets` は履歴として残すため、JSONの `legacyMeetId` は同名・同コースの既存レコードを指す。取込側はこの値を新しい年度のIDとして再利用しない。

## 整合性チェック

- 10大会・920行。各大会／コース内で `gender, age_min, age_max, event_code` の重複なし。全 `time` は `SS.ss` または `M:SS.ss` の文字列。
- `-----` の種目・性別・コースは記録なしとして行を作らない。
- 日本選手権、ジュニア特例枠、ジャパンオープンは既存シードの同一キー32行ずつと数値一致を確認した。既存レコードの年度が2025であるため、年度の上書きはしない。
- 夏季JOは公式2026表から再抽出した。既存シードよりSCM 6行、LCM 6行多く、同一キーではSCM 79行、LCM 83行の値が異なる。春季JOは2025公式表から再抽出し、既存シードより各コース16行多い。

リレー行は既存スキーマの `FRR_4X50`、`FRR_4X100`、`MRR_4X50`、`MRR_4X100` を使用した。年齢は標準記録表の区分に従い、`CS` は既存データモデルと同じ17–18歳としている。春季JOのリレーも、公式表の `CS` 区分を17–18歳で収録している。

# 検索UI改善の確認（2026-09-09）

## 実装

- 全国・九州・鹿児島のボタンで切替。同一地域・大会名を1カードに統合し、大会数を表示。
- 1つの大会だけを展開。保存済み大会・水路を復元し、利用できない場合は表示可能な先頭へ戻す。水路の初期順は長水路・短水路・共通。
- 初回は男子・年齢全選択。「全選択」ボタンで一括選択できる。性別・年齢のボタンを中心に配置し、選手名・履歴と表示説明は初期状態で折りたたむ。
- 結果画面の条件変更は検索ボタン不要。年齢未選択では表を隠す。前回条件があればホームから結果へ自動で移動。
- 既存の履歴キーとURL条件を維持。URLの明示条件が端末の保存条件より優先。旧 `compareAges`、`course=SCM/LCM` にも対応。
- `AbortController` とリクエスト条件の一致確認により、連続操作後に古い応答を表示しない。通信失敗時は条件を保って再試行。保存機能が使えなくても検索可能。
- タイムは結果表示だけで先頭のゼロを省略。小数第2位、右揃え・等幅数字を維持。横長の表は表内だけスクロールし、種目列を固定。
